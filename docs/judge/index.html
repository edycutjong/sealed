Run it, don't read it.

Two commands settle the whole claim: one re-runs every published verdict on your machine, the other proves the demo payouts from chain data.

make replay

Re-runs every published commit under wasmtime from the verifier wasm its bounty pinned (sha256-checked): 29 OK · 0 FAIL, with validateInstance → 1 for a real exploit, 0 for a fake (the 4 malformed inputs stop before that call). Offline.

offline · no NEAR account

make verify-demo

Reads chain data from a public archival RPC and proves the 5 of 5 paid demo-bounty runs: pinned hash, the operator's scoped worker key, verdict, delivery hash and PAID (about 1.5 min).

archival RPC · ~25 calls

Honest by design

What this does not prove yet.

  1. Testnet only. The mainnet leg is prepared (scripts/mainnet_leg.py) and has not run.
    README · Honest limits, item 1
  2. Worker attestation. make verify shows the request pinned the verifier hash and the operator's OutLayer worker key answered (a FunctionCall key limited to OutLayer's contract, its method list including resolve_execution). It checks the key, not its TDX quote, and does not show the worker ran exactly those bytes. make replay re-runs the same bytes locally.
    README · Honest limits, item 2
  3. No outside users yet. The measured demo is our own hunter agent plus the fakes corpus.
    README · Honest limits, item 7

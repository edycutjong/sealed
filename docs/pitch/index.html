How a bounty runs.

SEALED · v0.1.0 · ARCHITECTURE.md “Commit to payout” · scripts/hunter.py
The bounty is created from one global contract hash with no access keys. The hunter's exploit never touches the chain in clear: it is an OutLayer secret only this bounty's request can read. The verdict comes back through resolve_execution, and delivery is checked against the hash the worker attested.
